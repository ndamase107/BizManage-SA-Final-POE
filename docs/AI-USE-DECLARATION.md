\# AI-Use Declaration



\## BizManage SA — PROG7312 Final POE



I used ChatGPT and Codex extensively during the development of BizManage SA. Their assistance included planning, generating substantial sections of code, explaining implementation steps, diagnosing errors, suggesting tests and drafting documentation. This declaration was also drafted with AI assistance.



AI-generated code contributed to the Kotlin Android application, Jetpack Compose screens, Room persistence, WorkManager synchronisation, Firebase authentication, biometric access, notifications, image handling and the Node.js REST API. AI also assisted with GitHub Actions and Azure deployment configuration.



My contribution included integrating the supplied code into Android Studio, configuring the external services, running commands and tests, reporting errors, applying corrections and checking the resulting behaviour. I tested the application on an Android device and recorded a demonstration lasting five minutes and thirty-three seconds.



I did not accept every generated solution as correct without testing. Development involved resolving dependency incompatibilities, build failures, emulator problems, authentication configuration and network connection errors. I also checked offline synchronisation, duplicate-request protection, stock validation, product conflict handling and low-stock notification delivery.



The experience showed me that a successful build alone does not prove that an application works correctly. Unit tests, API integration checks and device testing provided different forms of evidence. For example, synchronisation required checks that repeated requests would not deduct stock twice or overwrite newer cloud information.



The implementation still has limitations, including incomplete translation coverage and inconsistent use of MVVM across screens. I have documented these rather than presenting unfinished features as complete.



I acknowledge that substantial parts of the submitted code and documentation were produced with AI assistance. I remain responsible for reviewing the submission, understanding its behaviour, explaining its implementation and accurately reporting what has been tested.
