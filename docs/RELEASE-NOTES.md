\# BizManage SA - Final POE Release Notes



Release date: 7 November 2026



\## Included features



\- Google sign-in and optional biometric access.

\- Inventory, product-based sales, customers and expenses.

\- Room local storage and WorkManager offline synchronisation.

\- Upload retries, duplicate-operation protection and product conflict review.

\- Authenticated REST API hosted on Azure over HTTPS.

\- Cloud Firestore storage and Cloudinary product photo integration.

\- Firebase Cloud Messaging, including sale-triggered low-stock alerts.

\- English, isiZulu and Sesotho language resources and selection.



\## Validation



\- Android debug build and unit-test workflow passed.

\- Backend test and deployment workflow passed.

\- Live API and product retry checks passed during development.

\- Physical Android demonstration recorded: 5 minutes 33 seconds.

\- Signed release APK generated successfully.



\## Known limitations



\- Some interface text remains in English.

\- MVVM is not consistently applied across all screens.

\- Product photo upload requires explicit final device verification.

\- The signed release APK has not been tested on a device.

\- Historical sales are not fully restored from the cloud.

\- Business profile settings and legacy amount-only sales remain local.

\- Photo uploads require an internet connection.

\- Free Azure hosting can pause while inactive.
